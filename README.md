# Focus Flow

A self-contained, production-ready web application for Focus & Spatial Planning.

## How to Deploy to GitHub Pages (Takes 30 seconds)
1. Upload all contents of this folder (index.html, .nojekyll, README.md) to your GitHub repository.
2. In your GitHub repository, go to **Settings** -> **Pages**.
3. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** (or master), folder: **/ (root)**
4. Click **Save**. Your site will be live at https://<username>.github.io/<repo>/!
